# Research Source Evidence

Use this skill for read-only evidence gathering.

1. Prefer primary sources, official documents, competition pages, datasets, and original repos.
2. Record source URL, publication/update date, access date, and what the source actually supports.
3. Separate facts from inference. Mark uncertainty explicitly.
4. Do not download bulk data, write files, or commit artifacts unless a task manifest grants paths.
5. Hand off concise evidence tables with:
   - claim
   - source
   - date
   - confidence
   - caveat
   - next verification step
