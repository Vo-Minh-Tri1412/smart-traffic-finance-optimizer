# Notebooks

These notebooks are cloud-runtime entrypoints for Colab/Kaggle.

- `00_colab_kaggle_setup.ipynb`: clone repo, install dependencies, mount/attach Drive.
- `01_yolo_train_colab.ipynb`: YOLO training skeleton.
- `02_rl_train_sumo_colab.ipynb`: SUMO-RL training skeleton.
- `03_export_artifacts_to_drive.ipynb`: package run outputs and push/copy to Drive.

The notebooks are intentionally thin. Real logic should live in `ai_quantum_hvtc/` or `scripts/`.
